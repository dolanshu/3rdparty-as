# Review 文档裁决规则（自动注入，始终生效）

任何 `docs/reviews/` 下的 review record 文档，必须在正文末尾包含一个 `## Adjudication` 节。

## 必填表格列

| ID | 来源 | 问题摘要 | 裁决 | 修改方案 | 状态 | 验证方式 | 备注 |

- 裁决取值：接受 / 部分接受 / 驳回 / 待裁决
- 状态取值：待修改 / 已修改 / 已验证 / 已关闭
- 验证方式示例：文档更新 / 测试通过 / 行为观察 / 维护者确认

## 流程

1. 评审人写完 review record，列出 gap。
2. 维护者（或授权人）逐条裁决，agent 协助落盘。
3. 关闭 gap 前必须更新本表"状态"和"验证方式"两列。
4. 所有 P0 条目状态为"已关闭"前，对应文档不得进入下一阶段。

## 唯一权威

完整协作守则见仓库根目录 `AGENT.md` §3.2、§3.3。
