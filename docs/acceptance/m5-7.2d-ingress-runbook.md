## 检查项（关门必勾）

| # | 项 | 验证方式 |
|---|-----|----------|
| 1 | Controller 保留默认 `nginx.ingress.kubernetes.io` annotation **prefix** | `kubectl describe ingress` 见注解键名 |
| 2 | `no-tls-redirect-locations` **不**豁免 `/` | controller 配置审查 / 文档记录 |
| 3 | 客户 TLS Secret 挂载 | `tlsSecretName` 指向 Secret |
| 4 | HTTP 访问控制台/API 被重定向或拒绝 | 集群内 `curl -I -H 'Host: <ingress-host>' http://ingress-nginx-controller.ingress-nginx.svc/` → 301/308；或生产 LB |
| 5 | 浏览器 credentials 不经明文 HTTP | 仅 HTTPS 登录（同源） |
| 6 | `forwarded_allow_ips` / `AS_CONFIG_TRUSTED_PROXIES` 显式 CIDR | 非 `*`、非 `0.0.0.0/0` |

## M5-1d — 外部 PostgreSQL（kind）

| 步骤 | 说明 |
|------|------|
| 启动库 | `deploy/compose` 的 `postgres:12.22`，发布端口默认 **55432**（与 M5-0b integration 同一套角色/init） |
| Runtime DSN | Secret `as-config-runtime` 的 `AS_CONFIG_DSN` 使用 **`as_config_web`**（非 owner）；**禁止**把 owner DSN 放进 runtime Secret |
| kind 网络 | Pod 访问宿主机 PG：`postgresql://as_config_web:…@<docker-gateway>:55432/as_config`（`m5-lib.sh` 自动取 `as-m5-control-plane` 网关） |
| 迁移 | 若库为空，需先跑 `as-config-migrate`（owner DSN，手动）；compose init 已建 role 时通常只需 schema 与 M4b 一致 |

占位 DSN `postgres:5432` **仅集群内 Service 名**，compose 未装进 kind 时会 **CrashLoop**；Ingress 对象仍可创建，但 **Ready 证据**依赖 M5-1d。

## ingress-nginx admission webhook（跟踪项）

| 情况 | 动作 |
|------|------|
| `ingress-nginx-admission-create` Job **Complete** | 正常继续 |
| Job 超时 / 失败 | 脚本 **WARN** + log `admission_job_ok=0`；查 `kubectl -n ingress-nginx get jobs,pods`；**不要**无记录地删 VWC |
| kind 开发例外 | 维护者在 evidence log 中记原因；生产路径必须 Job 成功或按客户 ingress 规范配置 |

## 公司 HTTP 代理

设置 `http_proxy` 时，宿主机 `curl localhost` 会走代理 → **403/000**。验证 config-service：`NO_PROXY=127.0.0.1,localhost kubectl port-forward` 或 `make m5-kind-verify`。

## 宿主机 80/443 与集群内 ingress curl

默认 `m5-kind-up.sh` **未**映射 hostPort 80/443。部分 kind 环境对 ingress Controller 的集群内 HTTP 会出现 **empty reply**（curl 52）。

| 口径 | 要求 |
|------|------|
| **M5-1c / §4.5 切片证据** | Ingress 对象 + 注解（表项 1–3、6）+ config-service **Ready**；`make m5-kind-verify` 的 **port-forward HTTP 200** |
| **M5 维护者签字 / §217③ / M4b-7.2d 关门** | **必须**完成表项 **4–5**（经 ingress 的 301/308 或等价 + 浏览器仅 HTTPS）；port-forward **不能**顶替。kind 上可用 `extraPortMappings` 或客户 ingress 采证；empty reply 视为 **未过关**，需修环境或换采证路径，**不得**在 plan 里勾 7.2d 关门 |
