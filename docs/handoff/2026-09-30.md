### M4b-6b durable audit API/store integration（2026-10-02；工程证据，非 acceptance）
- `PostgresAuditStore` 保存 actor/action/resource/outcome/time 与 canonical before/after snapshots；detail 不持久化。Credential-key/value 与 PEM private-key 检查为 heuristic；producer allow-list/redaction 仍必需。快照上限 64 KiB，safe metadata 有长度/字符边界。专用非-public schema 经显式 migration/owner setup；catalog/object、列/default/constraints/triggers 与 ascending bigint sequence 检查；不支持 partition/publication，保留 history guard 防序列倒退。Owner triggers 阻止 mutation/truncate。Runtime role NOLOGIN、无 CREATEROLE/membership，仅 schema USAGE、table SELECT + 排除 `id` 的 INSERT、sequence USAGE/SELECT；无 schema CREATE/table mutation。启动校验 role，单独 login role 必须 `SET ROLE`。
- 默认 `create_app` 要求 durable audit store；只有显式 `allow_unaudited_callback_mode=True` 才允许 legacy/test callback mode，且与 session auth 不兼容。请求级 serialization 与精确共享 PG connection；audited writes `commit=False` staging 后与 audit append 同事务提交；业务失败 rollback mutation，再写 DENIED/null snapshots；audit unavailable 时 generic 500 fail-closed。All requests audit allowed/denied；internal API catchall 覆盖 unmatched GET/HEAD 与 POST/PUT/PATCH/DELETE/OPTIONS/TRACE/CONNECT，同时保留 identity/permission/CSRF checks。Session path 使用 template + sorted parameter-name HMAC-SHA256 full digest，不存 raw path/query；外部配置稳定 32-byte key，rotation breaks cross-period correlation。
- **M4b-6b 阶段历史验证快照**：affected workflow matrix **264 passed, 3 skipped, 15 warnings**；API/audit catchall **89 passed, 15 warnings**；config-service integration **122 passed, 3 skipped, 404 deselected** on PostgreSQL 12.22；3 publication DDL tests 因需 `wal_level=logical`、当前为 `replica` 而 skipped。该阶段最后成功完整 `make gate` **767 passed, 2 skipped, 131 deselected**。CI 未运行，PG16 未测。最终 integrated review 修复后无 actionable findings；维护者签字待补。不是 REQ-S-4/M4b/M4 acceptance，详见 [review](../reviews/m4b-6b-audit-integration-review-2026-10-02.md) 与 [report](../acceptance/report.md)。

5. 在适配器获授权并实现后运行产品 E1 S1–S11；另行解决 E4 TLS 证书轮换。当前 native S1/S4 仍是探索性 smoke，不是产品验收，K2 未放行。
6. **X2 解锁**：在真实集群跑一次滚动升级 + 一次缩容，补 M5 剩余验收。
7. 处理 R1（D8）：补 testbed/容量压测 REQ，或调整 ADR-0014 指向；M6 启动前不假设容量数字（AGENT.md §6）。
